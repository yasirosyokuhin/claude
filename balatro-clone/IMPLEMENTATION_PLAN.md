# Balatro クローン 実装計画書

**担当割り**: 計画 = Fable / 実装 = Sonnet / 最終チェック = Fable
**ブランチ**: `claude/balatro-browser-clone-8itqbx`
**配置**: `balatro-clone/` ディレクトリ配下

## 0. 技術方針

- **Vanilla JS (ES Modules) + HTML + CSS**。ビルド不要、依存ゼロ。
- ES Modules は `file://` では動かないため、`python3 -m http.server` 等の静的サーバで起動する前提。README に起動方法を書く。
- 状態は単一の `game` オブジェクトに集約し、UI は `render()` で全再描画するシンプル構成(差分描画はしない)。
- 乱数は `Math.random` でよい(シード再現は対象外)。
- 日本語 UI。

## 2. ゲーム仕様(スコープ)

### 2.1 基本ループ
1. **ブラインド選択画面**: Small → Big → Boss の順に挑戦(スキップは実装しない。ボタンは「挑戦」のみ)。
2. **プレイ画面**: 手札8枚。1〜5枚選択して「プレイ」or「捨てる」。
   - ブラインドごとに **ハンド4回 / ディスカード3回**(ジョーカー等で増減可)。
   - 必要チップ達成で勝利 → 報酬 → ショップ → 次ブラインド。
   - ハンドを使い切って未達なら **ゲームオーバー**。
3. **アンティ8のボス撃破で勝利**(エンドレスは対象外)。

### 2.2 必要スコア
`base = [300, 800, 2000, 5000, 11000, 20000, 35000, 50000]`(ante 1〜8)
- Small = base×1、Big = base×1.5、Boss = base×2。

### 2.3 報酬($)
- Small $3 / Big $4 / Boss $5、+ 残ハンド数×$1、+ 利子(所持$5ごとに$1、最大$5)。

### 2.4 役と基礎値(チップ, マルト)
| 役 | chips | mult | 惑星カード |
|---|---|---|---|
| ハイカード | 5 | 1 | 冥王星 |
| ワンペア | 10 | 2 | 水星 |
| ツーペア | 20 | 2 | 天王星 |
| スリーカード | 30 | 3 | 金星 |
| ストレート | 30 | 4 | 土星 |
| フラッシュ | 35 | 4 | 木星 |
| フルハウス | 40 | 4 | 地球 |
| フォーカード | 60 | 7 | 火星 |
| ストレートフラッシュ | 100 | 8 | 海王星 |
- 惑星カード1枚で該当役が **+1レベル**(レベルごとに chips/mult が役固有量だけ増加。本家準拠の増加量は hands.js にテーブルで定義。例: ワンペア +15chips/+1mult)。
- A は 14 だが A-2-3-4-5 のローストレートも判定する。
- 秘密役(Five of a Kind 等)は**スコープ外**。ストーンカードは役判定から除外しチップのみ加算。

### 2.5 スコア計算パイプライン(scoring.js)
1. 役判定 → 役の (chips, mult) をレベル込みで取得。
2. **スコアしたカード**(役を構成するカードのみ)を左から順に処理:
   - チップ加算(ランク値 + bonus+30 / stone+50)
   - エンハンスメント: mult+4 / glass×2 / …
   - ジョーカーの「カードごと」トリガー(例: 特定スートで+mult)
3. 手札に残る steel カード: ×1.5 mult。
4. ジョーカーを左から順に「役ごと」トリガー(+chips → +mult → ×mult の順ではなく、**ジョーカー並び順で適用**。本家準拠)。
5. `score = floor(chips × mult)`。
- グラスカードは 1/4 で破壊。debuff されたカードは一切効果を発揮しない。

### 2.6 ジョーカー(15種、レアリティ: common/uncommon/rare)
最大所持5枚。売却可(購入価格の半額切上げ)。実装する15種:
1. **ジョーカー** ($2, c): +4 mult
2. **強欲なジョーカー** ($5, c): ♦がスコアするたび +3 mult
3. **色欲なジョーカー** ($5, c): ♥ +3 mult(同様に♠♣版の2種 → 計4種を1定義で量産)
4. **ずる賢いジョーカー** ($4, c): ツーペア含む役で +80 chips
5. **陽気なジョーカー** ($3, c): ワンペア含む役で +8 mult
6. **狂気のジョーカー** ($4, c): スリーカード含む役で +10 mult
7. **ミスプリント** ($4, c): +0〜23 mult(ランダム)
8. **バナー** ($5, c): 残ディスカード×+30 chips
9. **神秘の頂** ($5, c): ディスカード残0で +15 mult
10. **写真** ($5, c): 最初にスコアした絵札 ×2 mult
11. **ブラックボード** ($6, u): 手札が全て♠or♣なら ×3 mult
12. **キャンペーン** ($4, u): ブラインド勝利時、未使用ハンド1つにつき+$1(パッシブ表示のみ)
13. **サイコロ** ($6, u): ショップの初回リロール無料
14. **ホログラム** ($7, r): カードをデッキに追加するたび ×mult +0.25(累積)
15. **オベリスク相当は除外**。代わりに **カベンディッシュ** ($6, r): ×3 mult

### 2.7 消費アイテム(最大2枠)
- **惑星カード9種**: 対応役を+1レベル。
- **タロット8種**:
  - 魔術師: 選択1枚 → ワイルド化
  - 女帝: 選択1枚 → マルトカード化
  - 皇帝: タロット2枚をランダム生成(枠許す限り)
  - 恋人: 選択1枚 → ワイルド…ではなく本家準拠でグラス化は塔なので、恋人=ワイルド、魔術師=ラッキー相当は除外し **魔術師: ボーナス化 / 恋人: ワイルド化 / 塔: ストーン化 / 悪魔: グラス化 / 戦車: スチール化** に整理
  - 死神: 選択2枚 → 左のカードを右のコピーに変換
  - 太陽/月/星/世界(スート変換)から **太陽: ♥化** のみ採用
  - 合計8種: 魔術師(ボーナス)/女帝(マルト)/恋人(ワイルド)/戦車(スチール)/悪魔(グラス)/塔(ストーン)/死神(コピー)/太陽(♥化)
- 使用はプレイ画面・ショップ画面のどちらでも可(カード選択が必要なものはプレイ画面のみ)。

### 2.8 ショップ
- 枠: **売り物2枠**(ジョーカー60% / タロット25% / 惑星15%)+ **リロール$5(毎回+$1)**。
- ブースターパック・バウチャーはスコープ外。
- 所持金不足なら購入不可。次のブラインドへ進むボタン。

### 2.9 ボスブラインド効果(6種からアンティごとにランダム)
1. **鉤爪**: 全ての♥をdebuff
2. **水**: ディスカード0でスタート
3. **窓**: 全ての♦をdebuff
4. **首**: 全ての♠をdebuff
5. **マニキュア**: 手札が1枚少ない(7枚)
6. **針**: ハンド1回のみ(必要スコアはbase×1のまま)

### 2.10 UI 画面
- **上部HUD**: 現在ブラインド名・必要チップ・現在スコア、役名+chips×multのライブ表示、所持$、アンティ、残ハンド/ディスカード。
- **中央**: 選択中カードのプレビュー(役名表示)、手札(クリックで選択、最大5枚)。
- **左**: ジョーカー枠5。**右**: 消費アイテム枠2。
- **ソートボタン**: ランク順/スート順。
- **演出**: スコア加算はカードごとに軽いポップ(CSS アニメ、setTimeout チェーンで十分)。
- ダークグリーンのフェルト調背景、カードは CSS 描画(画像アセット不使用)。

## 3. 実装順序(Sonnet 用チェックリスト)

1. `hands.js` — 役判定 + レベルテーブル。**先に Node で単体確認**(`node --input-type=module -e` でストレート/ロー A ストレート/フルハウス等を assert)。
2. `scoring.js` — パイプライン。ジョーカー/エンハンスメントはコールバック注入で疎結合に。
3. `jokers.js` / `consumables.js` / `blinds.js` — データ定義。
4. `game.js` — 状態機械: `BLIND_SELECT → PLAYING → ROUND_WON → SHOP → (次ブラインド) → … → GAME_OVER / WIN`。
5. `shop.js`。
6. `index.html` / `css/style.css` / `ui.js` / `main.js` — UI。
7. `README.md`(起動: `cd balatro-clone && python3 -m http.server 8000`)。
8. **動作確認**: Playwright(`/opt/pw-browsers/chromium`, executablePath 指定)で起動→カード選択→プレイ→スコア反映までをスクリプトで確認し、スクリーンショット取得。
9. コミット & `git push -u origin claude/balatro-browser-clone-8itqbx`。

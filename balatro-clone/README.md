# Balatro クローン (ブラウザ版)

ビルド不要、Vanilla JS (ES Modules) だけで動くブラウザゲームです。

## 遊び方(起動)

ES Modules は `file://` では読み込めないため、簡易的な静的サーバーで起動してください。

```bash
cd balatro-clone
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## ルール概要

- 標準52枚のデッキから8枚の手札を持ち、1〜5枚を選んでポーカーの役を作って「プレイ」します。
- ブラインドごとに **ハンド4回 / ディスカード3回** まで。必要スコアに到達すればブラインド撃破です。
- スモール → ビッグ → ボスブラインドの順に挑戦し、アンティ8のボスを倒すと勝利です。
- ショップでジョーカー・タロットカード・惑星カードを購入して強化しましょう。
  - **ジョーカー**: スコア計算に様々な効果を追加します(最大5枚所持)。
  - **タロットカード**: 手札のカードにエンハンスメントを付与します。
  - **惑星カード**: 対応する役のレベルを上げ、基礎チップ/マルトを恒久的に強化します。
- ボスブラインドでは特殊なルール(特定スート無効化・手札減少・ハンド1回のみ等)が課されます。

## ファイル構成

- `js/cards.js` — カード/デッキ定義
- `js/hands.js` — 役判定・役レベルテーブル
- `js/scoring.js` — スコア計算パイプライン
- `js/jokers.js` — ジョーカー定義
- `js/consumables.js` — タロット・惑星カード定義
- `js/blinds.js` — アンティ/ブラインド/ボス効果
- `js/game.js` — ゲーム状態機械(ショップロジック含む)
- `js/ui.js` / `js/main.js` — 描画・イベント制御

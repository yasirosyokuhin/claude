# 北海道つりゲーム

北海道の実在する河川・ダムを舞台にした、ブラウザだけで遊べる釣りゲームです。スマートフォンなどの縦画面表示を前提に作られています。サーバー不要・単一HTMLファイルで完結しており、`index.html` を開くだけですぐに遊べます。

## 遊び方

1. **タイトル画面** で「▶ 釣りを始める」をタップします。
2. **地図選択画面** で北海道地図上のマップピン（青＝河川／茶＝ダム。白い波紋が広がっている場所は釣り可能）をタップすると、その場所の情報カード（名称・種別・地域・看板魚など）が表示されます。「ここで釣る」でその場所に決定します。地図は**ピンチで拡大・ドラッグで移動・ダブルタップでズーム切替**ができます（拡大は地図の枠内のみで、ページ全体は拡大されません）。
3. **タックル選択画面** で所持している竿（最初は**のべ竿**のみ。釣具店で買い足すとルアーロッド／フライロッド／大物ロッドが増えます）を選び、続けてその竿で使えるルアー・エサを選んで「🎣 釣り開始」をタップします。
4. **釣り画面** — 本格的な釣りフローです。
   - **キャスト**: 竿が振られ、ウキが放物線を描いて着水します。
   - **アタリ待ち**: ウキがゆらゆら漂います。実際の時刻に応じて空が変わり（朝マズメ／日中／夕マズメ／夜釣り）、**マズメ時はアタリが早く、ボウズ率も下がります**。
   - **アタリ**: ウキが沈み、水中に**魚影**がゆらめきます（魚影の形で魚種を推理できます。魚影のないアタリは藻かも…）。素早くタップしてアワセ！（約1.3秒以内）
   - **ファイト**: 掛けたら**長押しで巻き上げ**。魚が暴れて竿がしなり、テンションゲージが上下します。**緑ゾーンにテンションを保つと「寄せ」が進み**、巻きすぎるとラインブレイク、緩めすぎるとフックオフ。**サイズとレア度で難易度が変わり**、大物・レア魚はゾーンが狭く・揺れ動き、突然の**「走り」**（握ったままだと一瞬でブレイク。離してしのぐ）が襲ってきます。45秒以内に寄せきれないと「すっぽ抜け」。アワセ猶予もレア魚ほど短くなります。
   - **ランディング**: 寄せ切ると魚が水面から跳ね上がって釣り上げ成功！
5. **結果画面** で釣れた魚（またはボウズ／バラシ）が表示されます。初めて釣った魚には「NEW!」が付きます。そのまま同じ場所で再挑戦したり、場所を変えたり、図鑑を確認したりできます。
6. **図鑑画面** では、これまでに釣った魚種の一覧と、捕獲数（例: 7/16）、レア度別の捕獲状況を確認できます。

### サウンドと振動

- 効果音（キャスト音・着水音・リール音・キャッチ音）と環境音（川のせせらぎ・湖の静けさ）は、すべて**Web Audioでその場で合成**しています（外部音源ファイルなし）。釣り画面右下の🔊ボタンでミュートできます（設定は保存されます）。
- 対応端末では、アタリ・ヒット・ラインブレイク時に**バイブレーション**が作動します。

## ハマる仕組み（進行システム）

- **釣り人ランク**: 釣り・おたから発見・ミッション達成でお金とは別の**経験値**が貯まり、Lv.1〜20まで成長。上がるほど特典が解禁——**釣行キャスト+1／+2**、**釣具店の割引（8%→15%）**、**特別な個体（👑大物・🌸婚姻色）が出やすくなる**、**いけすの枠増加**、Lv.20で称号「北の釣聖」。タイトル画面にランクバーが常に伸びていきます。
- **竿で段階的に強くなる（RPGサクセス）**: 最初は**のべ竿**一本から。ウグイ・フナ・ドジョウ・ワカサギなどの**小物**が中心で、大きなマスやサケ・イトウはめったに掛かりません。稼いだお金で**ルアーロッド**（マス類の本命）→**フライロッド**（渓流魚）→**大物ロッド**（イトウ・大鮭・ヌシに立ち向かう最終装備）と竿を買い進めるほど、狙える魚のクラスとサイズが上がっていきます。竿は掛かりやすさだけでなくラインの強さ・寄せ速度にも影響します。
- **サイズと自己記録**: 釣るたびにサイズ（cm）を抽選（大物ほど稀。ゲーム用のデザイン値で、実測データベースの値ではありません）。弱い竿ほど小型・剛竿ほど大型が出やすくなります。大きい魚ほど引きが強く長期戦に。図鑑に自己ベストが残り、記録更新で演出が入ります。低確率で**👑大物**・**🌸婚姻色**の特別個体も。
- **サケ・イトウは終盤の花形**: サケはレア魚扱いで、川では専用の高額な**サーモン仕掛け**（ウキ＋スプーン＋タコベイト）＋強い竿でないと本気で口を使いません。イトウは「幻の魚」枠で、大物ロッド＋ミノーで聖地・天塩川に通ってようやく手が届きます。どちらも引きが強烈で、釣り上げれば高値・大きな達成感に。
- **お金と釣具店**: 釣果はサイズとレア度に応じて換金。竿・ルアー・強化パーツ（ライン強化=切れにくい／ハイギアリール=寄せが速い）を購入して装備を育てます。
- **遠征の解禁**: 最初はウグイ・ドジョウ中心の入門河川**発寒川**と、身近な**漁川ダム（えにわ湖）**の2ヶ所だけ。稼いだお金でまず**豊平川**（サケの川・1,200円）→**石狩川**（大河・2,000円）と広げ、川・ダムを解禁していき、最後はイトウの聖地・天塩川へ（50,000円）。
- **今日の釣り便り**: 日替わりで天気（晴/曇/雨）と「荒食い」の魚種・狙い目の釣り場が変わります（雨の日はイワナ類の活性UP）。天気は釣りシーンの見た目にも反映。
- **記録の間と称号**: 総釣果・総収入・最大魚を記録。実績で「イトウマスター」「北海道制覇」などの称号を獲得。

## 釣行・大会・イベント・番屋

- **釣行（ラン制）**: 1回の釣行はキャスト8投。小物はテンポよく連続、レア魚や記録更新はフル演出。納竿すると**釣行リザルト**で釣果一覧・スコア（サイズ×レア度＋種類/大物/ノーバラシボーナス）・売却精算。
- **本日の大会**: 毎日どこか1ヶ所が大会会場（🏆マーク・未解禁でも当日無料開放）。釣行スコアで**NPC釣り師10人のリーダーボード**に挑み、順位に応じて賞金（1位5,000円＋称号）。
- **道中イベント**: 釣行中に事件が起きる——🐻ヒグマ（3秒動くな）、🦅オジロワシ（3タップで獲物を守れ）、👴地元の名人（明日の大会情報・半額販売・一本勝負）、🌦夕立、⚡入れ食い、🗺地図の切れ端、ほか10種。
- **ヌシ**: ほとんどの釣り場に名前つきの主が1体（例: 石狩の大帝「銀鱗」は夜だけ。入門河川・発寒川には主はいません）。出現条件を満たすと低確率で襲来、討伐で報奨金と剥製。**地図の切れ端3枚で幻の湖・朱鞠内湖が出現**——日本最大のヌシ「朱鞠内の大帝」142cmが待つ。
- **キャストメーター**: タップで止める往復バー。沖に飛ばすほど大物、失投はボウズ率UP。
- **川のおたから & がらくた**: 1投ごとに低確率で魚の代わりに**アイテム**が掛かります。
  - **がらくた**（空き缶・長靴・流木ほか）は「🧹 川のおそうじ」に加算。貯めると称号「川の守り人」やユキのなつき度に。
  - **おたから**（古銭・翡翠・化石・砂金・まりも・流氷のかけら…全14種）は換金でき、新規発見は**💎たからもの図鑑**に登録。地域限定品（日高=翡翠、オホーツク=流氷/黒曜石、道東=まりも、空知=石炭）や、**セット完成ボーナス**（宝石・古代ロマン）もあります。地図の切れ端もこの図鑑に統合表示。
- **🏕 番屋**: いけす水槽（釣った魚を3匹まで泳がせて眺める）、燻製小屋（最大の1匹を預けるとリアル30分で売値2.5倍）、トロフィーの壁（ヌシと自己記録の剥製）。

## ナビキャラ「ユキ」

番屋の看板娘**ユキ**（釣り名人のおじいちゃんを持つ、シマエナガの髪飾りがトレードマークの女の子）が、釣りのすべてに寄り添います。ちびキャラのSVGで表情差分5種×きせかえ5種。

- **ナビ**: 時間帯で変わる挨拶、アタリ・大物・記録更新・ヌシ遭遇・バラシ…場面ごとに吹き出しで実況（元気な女の子口調）
- **ユキのおねがい**: 日替わりミッション3本（「◯◯を2匹」「40cm超え」「大会に出て」など）。達成で賞金＋**なつき度**
- **なつき度 Lv.1〜10**: 上がるほど仲良しに——きせかえ解禁（マフラー/ニット帽/麦わら/金リボン）、番屋に遊びに来る、Lv5でお守り（マズメのボウズ率ダウン）、Lv10で称号「ユキの相棒」
- **ユキの部屋**: タイトルのユキをタップ。つんつんすると喋る、きせかえ、ごほうび一覧、思い出アルバム

## 収録データ

- 実在の**河川13河川**・**ダム10ダム**（北海道内の各地域から選定。入門用の小川・発寒川を含む）
- 釣り場ごとに実際の地形に基づく**専用の情景**を描画します（例: 尻別川=羊蹄山、釧路川=湿原とタンチョウと朝霧、豊平川=札幌の街明かりと橋、豊平峡ダム=峡谷、大雪・忠別ダム=雪の高峰、湧別川・沙流川=渓流の岩と白泡…）。川幅も大河・中流・渓流で変わります
- **魚類16種**（同一種の亜種・型は1エントリに統合。例: サクラマス＝ヤマメ、アメマス＝エゾイワナ、カジカ＝各卵型を含む）
- 場所ごとに実在の生息魚種のみが釣れるように設定し、竿・ルアー／エサの組み合わせによって釣れやすさが変化します。イトウ（日本最大の淡水魚）は天塩川・釧路川水系など一部の場所にのみ、ごく低い確率で登場する「伝説枠」です。

## データ出典について

本作に収録している河川・ダムの選定および生息魚種の情報は、国土交通省「河川水辺の国勢調査（河川環境データベース）」（<https://www.nilim.go.jp/lab/fbg/ksnkankyo/>）で公開されている調査結果を参考にしています。

- 魚のサイズ・個体数などの詳細な調査データは扱わず、**生息する魚の種類のみ**を参考にしています。
- 同一種の亜種・地方型（例: サクラマスとヤマメ、アメマスとエゾイワナなど）は、ゲーム上は**同一種として1つに統合**して扱っています。
- 抽選確率（重み付け）やルアー／エサごとの倍率は、実際の生息傾向を参考にしつつ、**ゲームとして遊びやすくなるよう独自に簡略化・調整**した数値です。学術的な生息密度や漁獲統計そのものではありません。

### 地図データの出典

- **海岸線（本島・離島）**: OpenStreetMap由来のデータセット `dataofjapan/land`（ODbL）を基にした北海道の実座標です。
- **石狩川の流路**: Natural Earth 10m の河川データによる実ポリラインです。
- **他11河川の流路**: 士別・名寄・帯広・弟子屈など実在の主要経由地に基づく簡略化ポリラインです。
- **湖（サロマ湖・屈斜路湖・支笏湖・洞爺湖・阿寒湖・網走湖）**: 実在位置に基づく近似形（ガーニッシュ用途）です。
- 魚のイラストは、上記の地理データとは別に作成したオリジナルのパラメトリックSVGです（実在の写真・イラストの複製ではありません）。

## 起動方法

追加のインストールやビルド、サーバーは一切不要です。

```
index.html をブラウザで開くだけ
```

`file://` で直接開いても動作します（外部CDN・外部フォント・外部画像などの通信は一切発生しません）。

## データ保存について

図鑑（これまでに釣った魚種の記録）は、ブラウザの `localStorage`（キー: `hokkaido_fishing_zukan_v1`）に保存されます。ページを再読み込みしても記録は保持されます。ブラウザのデータを削除したり、別のブラウザ・別の端末で開いたりすると記録は引き継がれません。保存データが壊れていても、ゲーム自体はエラーにならず初期状態から遊べます。

## ファイル構成

- `index.html` … ゲーム本体（単一ファイル完結。データもすべてこのファイル内に記述）
- `data/hokkaido_fishing.json` … 収録している河川・ダム・魚類データを読み物として書き出したもの（内容は `index.html` 内のデータと一致しています。ゲーム本体はこのJSONを読み込まず、`index.html` 内のデータのみで動作します）

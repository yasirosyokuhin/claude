# 北海道つりゲーム

北海道の実在する河川・ダムを舞台にした、ブラウザだけで遊べる釣りゲームです。スマートフォンなどの縦画面表示を前提に作られています。サーバー不要・単一HTMLファイルで完結しており、`index.html` を開くだけですぐに遊べます。

## 遊び方

1. **タイトル画面** で「▶ 釣りを始める」をタップします。
2. **地図選択画面** で北海道地図上のマーカー（河川＝●／ダム＝◆）をタップすると、その場所の情報カード（名称・種別・地域・看板魚など）が表示されます。「ここで釣る」でその場所に決定します。
3. **タックル選択画面** で竿（ルアーロッド／フライロッド／のべ竿）を選び、続けてその竿で使えるルアー・エサを選んで「🎣 釣り開始」をタップします。
4. **釣り画面** で「キャスト中…」の演出のあと、ランダムなタイミングで「！ アタリ！ タップ！」が表示されます。表示から約1.3秒以内にタップできれば成功、遅れると「バラシ（逃げられた）」になります。
5. **結果画面** で釣れた魚（またはボウズ／バラシ）が表示されます。初めて釣った魚には「NEW!」が付きます。そのまま同じ場所で再挑戦したり、場所を変えたり、図鑑を確認したりできます。
6. **図鑑画面** では、これまでに釣った魚種の一覧と、捕獲数（例: 7/16）、レア度別の捕獲状況を確認できます。

## 収録データ

- 実在の**河川12河川**・**ダム10ダム**（北海道内の各地域から選定）
- **魚類16種**（同一種の亜種・型は1エントリに統合。例: サクラマス＝ヤマメ、アメマス＝エゾイワナ、カジカ＝各卵型を含む）
- 場所ごとに実在の生息魚種のみが釣れるように設定し、竿・ルアー／エサの組み合わせによって釣れやすさが変化します。イトウ（日本最大の淡水魚）は天塩川・釧路川水系など一部の場所にのみ、ごく低い確率で登場する「伝説枠」です。

## データ出典について

本作に収録している河川・ダムの選定および生息魚種の情報は、国土交通省「河川水辺の国勢調査（河川環境データベース）」（<https://www.nilim.go.jp/lab/fbg/ksnkankyo/>）で公開されている調査結果を参考にしています。

- 魚のサイズ・個体数などの詳細な調査データは扱わず、**生息する魚の種類のみ**を参考にしています。
- 同一種の亜種・地方型（例: サクラマスとヤマメ、アメマスとエゾイワナなど）は、ゲーム上は**同一種として1つに統合**して扱っています。
- 抽選確率（重み付け）やルアー／エサごとの倍率は、実際の生息傾向を参考にしつつ、**ゲームとして遊びやすくなるよう独自に簡略化・調整**した数値です。学術的な生息密度や漁獲統計そのものではありません。

### 地図データの出典

- **海岸線（本島・離島）**: OpenStreetMap由来のデータセット `dataofjapan/land`（ODbL）を基にした北海道の実座標です。
- **石狩川の流路**: Natural Earth 10m の河川データによる実ポリラインです。
- **他11河川の流路**: 士別・名寄・帯広・弟子屈など実在の主要経由地に基づく簡略化ポリラインです。
- **湖（サロマ湖・屈斜路湖・支笏湖・洞爺湖・阿寒湖・網走湖）**: 実在位置に基づく近似形（ガーニッシュ用途）です。
- 魚のイラストは、上記の地理データとは別に作成したオリジナルのパラメトリックSVGです（実在の写真・イラストの複製ではありません）。

## 起動方法

追加のインストールやビルド、サーバーは一切不要です。

```
index.html をブラウザで開くだけ
```

`file://` で直接開いても動作します（外部CDN・外部フォント・外部画像などの通信は一切発生しません）。

## データ保存について

図鑑（これまでに釣った魚種の記録）は、ブラウザの `localStorage`（キー: `hokkaido_fishing_zukan_v1`）に保存されます。ページを再読み込みしても記録は保持されます。ブラウザのデータを削除したり、別のブラウザ・別の端末で開いたりすると記録は引き継がれません。保存データが壊れていても、ゲーム自体はエラーにならず初期状態から遊べます。

## ファイル構成

- `index.html` … ゲーム本体（単一ファイル完結。データもすべてこのファイル内に記述）
- `data/hokkaido_fishing.json` … 収録している河川・ダム・魚類データを読み物として書き出したもの（内容は `index.html` 内のデータと一致しています。ゲーム本体はこのJSONを読み込まず、`index.html` 内のデータのみで動作します）
